# Coast to Coast — motorcycle itinerary

Open `index.html` in a browser (double-click works), or serve it:
`python3 -m http.server 8765` → http://localhost:8765

## Editing the trip
Edit **only `data/trip.js`**. Its header comment documents every field.
Days, dates, day numbers and totals are derived — change `nights`, add or remove a stop,
or change `meta.startDate`, and everything re-flows.

After changing coordinates, `via` points, explore `loop`s or `wiki` titles, run:

    node tools/build.mjs            # refetches only what changed
    node tools/build.mjs routes     # just road geometry (OSRM)
    node tools/build.mjs images     # just photos (Wikipedia / Commons)

Until you rebuild, a changed leg is drawn as a dashed straight line with an estimated distance.

## Files
- `data/trip.js` — the itinerary (hand-edited)
- `data/routes.js`, `data/gallery.js`, `images/` — generated by `tools/build.mjs`
- `index.html`, `app.js`, `styles.css` — renderer (no trip content)
